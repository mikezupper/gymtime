Act 2 Scroll-driven animations · Tier C

The scrollbar is the timeline

The progress bar pinned to the top of this page, the drifting blobs below, and the cards fading in are all animation-timeline — compositor-driven, zero scroll listeners. Unsupported browsers simply see everything, static.

These blobs move at three different speeds as you scroll.

scroll(root)

drives the fixed progress bar from page top to bottom.

view()

runs each card's fade as it crosses the viewport.

animation-range

maps entry 0% → cover 35% so reveals finish early.

Scroll-driven animations aren't supported in this browser — showing the fallback: all content rendered fully visible, no progress bar. That's the guard doing its job.

/* Tier C: everything inside the guard */
@supports (animation-timeline: scroll()) {
  .progress {
    animation-timeline: scroll(root);
    animation: grow-x linear both;
  }
  .reveal {
    animation-timeline: view();
    animation-range: entry 0% cover 35%;
  }
}

Act 3 Anchor positioning · Tier B

Popovers that refuse to fall off the screen

Each button below invokes a popover anchored to it — popovertarget creates the anchor implicitly, and position-try-fallbacks auto-flips it away from viewport edges. Try the first and last buttons, then resize the window narrow and try again. Not one line of positioning JavaScript.

Anchored to the left-most button. If I would overflow the left edge, flip-inline slides me back in.
Default placement is position-area: block-end — right under my anchor.
Scroll me near the bottom of the viewport and reopen: flip-block pops me above the button instead.
Right-edge case. Popper.js used to be an entire dependency for what is now three declarations.
<button popovertarget="tip">Open</button>
<div id="tip" popover>…</div>

[popover] {          /* implicit anchor! */
  position: absolute; inset: auto;
  position-area: block-end;
  position-try-fallbacks: flip-block, flip-inline;
}

initial-letter drop cap (Tier C)

Drop caps once meant absolutely-positioned spans and prayer. initial-letter: 3 3 sinks this letter three lines with correct cap-height alignment; unsupported browsers get the honest float fallback you're possibly reading now.
