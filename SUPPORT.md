# Getting help

Start with the [README](README.md), [role walkthrough](docs/workflows.md), [local development guide](docs/development.md), and [deployment guide](docs/deployment.md). The app's Help area explains organizer setup, coach actions, and parent subscriptions.

For a question or reproducible problem, open a [GitHub issue](https://github.com/mikezupper/gymtime/issues/new/choose). Include the commit or version, whether you use native development or Docker, the affected role, and steps to reproduce. Share only sanitized logs and fictional accounts. Omit secrets, sign-in codes, cookies, real team-calendar links, and database files.

Use the [security reporting channel](SECURITY.md) for vulnerabilities. This is a community project; support and review have no guaranteed turnaround time.
