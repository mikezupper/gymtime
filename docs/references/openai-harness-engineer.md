# Harness engineering reference

Gymtime uses repository documents, executable checks, and feedback from real screens to make development work reviewable. Product rules live in requirements; architecture defines ownership; checks enforce boundaries and detect drift. AGENTS.md is a navigation guide rather than a substitute for those documents.

For a change, reproduce the problem, implement the smallest coherent solution, verify the relevant behavior, and record the evidence and limits. Keep task status in a local tracker and durable decisions in the repository. When feedback reveals a missing rule, update the documentation or a mechanical check so future contributors can use it.

This approach is informed by Ryan Lopopolo's February 11, 2026 article, [Harness engineering: leveraging Codex in an agent-first world](https://openai.com/index/harness-engineering/). This file is an original project explanation, not a reproduction of the article. The source article remains on OpenAI's website.
